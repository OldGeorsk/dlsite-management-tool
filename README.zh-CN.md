# DLsite Tool

[English](README.md) | **简体中文**

一个用于整理本地 DLsite 音声收藏的网页工具。它可以扫描包含 RJ 号的作品目录，从 DLsite 日文作品页补全元数据，并提供搜索、筛选、资料库统计和 Excel 导出。

工具在本机运行，收藏记录和扫描结果保存在本地，不需要账号或云端服务。

## 主要功能

- 递归扫描本地目录，识别目录名中包含 `RJ` 加 6～9 位数字的作品目录。
- 使用本机 Everything 索引联想扫描根目录、打开作品目录，并在旧路径失效时按 RJ 补充定位。
- 同一个 RJ 号出现在多个位置时，合并为一条作品记录并保留多个本地路径。
- 从 DLsite 日文作品页补全官网标题、社团、声优、发售日、标签和封面 URL 等元数据。
- 刷新总售出数、平均评分和评价人数；单个作品失败不会中断整个批量任务。
- 在本地网页中用多关键词搜索作品，并集中组合社团、声优、发售年份和标签筛选。
- 按平均评分或评价人数升降序浏览，并查看各筛选项的联动作品数。
- 将当前检索结果或完整资料库及最新指标导出为 `.xlsx` 文件。

## 快速开始

### Windows 一键启动（推荐）

准备条件：

- Windows 10 或 Windows 11。
- Python 3.11 或更高版本。安装 Python 时请勾选 `Add python.exe to PATH`。

使用步骤：

1. 下载项目并解压到本地文件夹。
2. 双击项目根目录中的 `启动 DLsite 工具.bat`。
3. 首次启动时，脚本会自动创建 `.venv` 虚拟环境并安装 `requirements.txt` 中的依赖。
4. 服务启动成功后，浏览器会自动打开本地页面。

启动后的黑色窗口需要保持打开。关闭窗口或按 `Ctrl+C` 会停止本地服务。

### 开发者启动

在项目根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py
```

然后打开：

```text
http://127.0.0.1:8765
```

直接运行 `server.py` 时默认使用 8765 端口；Windows 一键启动器会从该端口开始自动寻找可用端口。

### 项目结构与维护

目录职责、启动入口、测试命令、维护脚本和本地数据位置见[项目目录索引](docs/PROJECT-STRUCTURE.md)。

## 基本使用

界面原生支持简体中文和英文，无需额外安装。首次访问时会跟随浏览器语言（中文浏览器显示中文，其他语言显示英文）；可使用页头的 **中文 / English** 按钮即时切换，选择会保存在本机并由两个页面共用。Excel 的工作表名、表头和状态显示会跟随当前界面语言。

1. 在网页中输入音声资料库的根目录路径。
2. 点击“扫描目录”，让工具识别其中的 RJ 作品目录。
3. 如需补全 DLsite 元数据，勾选“扫描后抓取官网信息”，或在扫描后单独抓取缺失信息。
4. 在“作品检索”中输入关键词，或展开社团、声优、发售年份和标签面板组合筛选；同类选项任选其一，不同分类同时满足。
5. 根据需要按平均评分或评价人数排序，或进入“资料库概览”查看统计。
6. 点击“导出当前结果”保存眼前的筛选与排序结果；点击“导出全库”保存完整资料库。

### 推荐的音声文件夹格式

建议每部作品使用一个独立文件夹，并按下面的格式命名：

```text
音声资料库/
├─ RJ00000001 作品标题/
│  ├─ 音声/
│  └─ イラスト/
└─ RJ00000002 另一部作品/
```

推荐格式为 `RJ编号 + 空格 + 作品标题`。实际识别较宽松：只要**文件夹名称中包含 `RJ` 加 6～9 位数字**即可，字母大小写不限，例如 `RJ00000001 作品标题`、`作品标题 [RJ00000001]` 和 `rj00000001_作品标题` 都能识别。RJ 号之外的文字会作为本地标题。

扫描会递归查找作品目录；某个目录一旦被识别为作品根目录，其内部的 `音声`、`特典`、`画像` 等子目录不会被重复识别。因此，请将 RJ 号写在每部作品最外层的文件夹名称中，并避免在分类目录名称中加入 RJ 号。同一个 RJ 号存放在多个位置时，工具会合并为一条作品记录并保留所有路径。

路径框输入至少 2 个字符后会通过 Everything 显示最多 20 个目录候选；选择候选只会填入路径框，仍需手动点击“扫描目录”。作品列表中的每条本地路径可以直接点击进入目录。若旧路径已经失效，页面会按 RJ 显示替代候选，也可以补充标题关键词或手动输入新路径。只有用户明确点击“添加路径”，且目录自身包含同一 RJ 时，工具才会追加保存；旧路径不会被自动删除。

### 代理设置

代理栏当前预填 `http://127.0.0.1:7892`。只有本机正在运行对应代理服务时才能使用该地址；否则请清空代理栏以尝试直连，或改成你自己的 HTTP 代理地址。

## 进阶操作

- 点击“刷新销量与评价”，补齐尚未抓取的总售出数、平均评分和评价人数。
- 勾选“强制刷新已有指标”后再次刷新，可以更新全库已有指标。该任务串行执行，作品较多时需要等待较长时间。
- 扫描、元数据抓取和指标刷新会在页面显示任务进度；同一时间只会运行一个后台任务。
- “资料库概览”支持按年份、抓取状态和本地路径组合筛选，并可从排行项目返回作品列表下钻查看。
- 搜索框支持用空格分隔多个关键词；所有关键词都需要命中，但可以分别出现在标题、RJ、社团、声优、标签或路径中。
- 四类筛选面板中的数字表示在其他当前条件下可匹配的作品数；已选条件会显示为可单独移除的标签，页面地址也会保留完整检索状态。
- 平均评分与评价人数排序会把未知值放在最后；未选择指标排序时默认按发售日最新优先。
- 指标未知时显示 `—`；将鼠标停留在对应位置可以查看刷新时间或失败原因。

## 数据安全与使用边界

- 工具默认只读扫描，不会重命名、移动、删除或修改任何音声文件。
- Everything 查询只访问本机已有索引，不开启 HTTP Server，也不会上传磁盘内容。查询词、候选路径和令牌不会写入 URL、SQLite、浏览器存储或文件日志；候选仅在当前页面和短时服务器内存中存在。
- SQLite 数据库、运行日志和导出的 Excel 文件均保存在项目本地目录中。
- 扫描与统计完全在本地完成；只有抓取元数据或刷新指标时，程序才会向 DLsite 发起网络请求。
- 单个 RJ 抓取失败会记录可读的失败原因，不会中断后续作品的处理。
- 动态指标只保存最近一次成功取得的值，不保存历史快照或变化趋势；刷新失败不会清空上次成功值。
- 本项目与 DLsite 官方无关联。DLsite 页面、接口或访问规则发生变化时，抓取功能可能暂时失效。
- 请根据所在地法律、DLsite 的使用规则和自身网络环境合理使用抓取功能，避免频繁请求。

## Everything 联动要求与降级

- 需要 Windows、正在运行且支持 IPC 的 Everything 正式版；Everything Lite 不支持 SDK/IPC。
- 项目会根据运行 Python 的架构选择 `vendor/everything-sdk/dll/` 中的 x86、x64、ARM 或 ARM64 DLL。
- 当前官方 SDK 固定连接未命名 Everything 实例，不支持命名实例。若使用 1.4/1.5 并存环境，请确保希望查询的实例使用默认未命名实例。
- Everything 未运行、索引未就绪、SDK 不兼容、搜索繁忙或超时时，页面会显示可读提示并保留手动输入；工具不会自动启动 Everything，也不会改为全盘遍历。
- SDK 查询在专用本地子进程中执行。单次查询超过 1 秒会终止并重建查询进程，避免拖住网页服务；连续热查询目标为从最后一次键入到候选显示 P95 不超过 400ms。

## 常见问题

### 双击启动文件后没有正常启动

确认已经安装 Python 3.11 或更高版本，并且安装时已将 Python 加入 `PATH`。也可以在项目目录打开 PowerShell，运行 `.\start-dlsite-tool.ps1` 查看错误信息。

### 浏览器没有自动打开

保持启动窗口开启，将窗口中显示的 `http://127.0.0.1:端口` 复制到浏览器地址栏打开。

### 无法抓取 DLsite 信息

先检查网络连接和代理设置。如果本机没有运行 `127.0.0.1:7892` 对应的代理，请清空代理栏尝试直连，或填写实际可用的代理地址。失败原因会显示在任务进度或作品记录中。

### 数据保存在哪里

- SQLite 数据库：`data/dlsite_tool.sqlite3`
- Excel 导出：`exports/dlsite_works.xlsx`
- 运行日志：`logs/`

这些目录保存的是本地资料库信息，不应随意上传或分享。
